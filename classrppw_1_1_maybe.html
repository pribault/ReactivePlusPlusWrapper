Detailed Description

template<detail::Value T>
class rppw::Maybe< T >

Cold source that succeeds with a value, completes empty or signals an error.

Template Parameters
TUnqualified value type satisfying std::copyable.

Success and empty completion are distinct terminal outcomes: onSuccess is never followed by onComplete. Each subscription executes its own chain. Operators do not modify the source; their exceptions are forwarded to onError. Without a scheduler, synchronous sources run on the thread calling subscribe().

Warning
Reference captures must outlive processing. The caller must synchronize data shared between subscriptions.

Starts processing with three mutually exclusive terminal outcomes.

Template Parameters
NType of the callback receiving T.
EType of the callback receiving std::exception_ptr.
CType of the no-argument callback for an absent value.
Parameters
onSuccessTerminal callback when a value is received.
onErrorTerminal error callback.
onCompleteTerminal callback when the source is empty.
Returns
Shared cancellation handle, disposed after success, error or empty completion.
Precondition
Callbacks must be const-invocable and must not throw.
Warning
An exception escaping a callback invokes std::terminate.
Note
Callbacks are retained throughout processing. Destroying the handle does not cancel the subscription. Cancellation does not interrupt a callback already in progress.
