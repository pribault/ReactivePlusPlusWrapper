Detailed Description

template<detail::Value T>
class rppw::Single< T >

Cold source whose success produces exactly one value.

Template Parameters
TUnqualified value type satisfying std::copyable.

Each subscription receives success or an error, unless cancelled or the source never terminates. Success is terminal, with no completion callback. Operators compose a new chain; producer exceptions are forwarded through std::exception_ptr. Without a scheduler, synchronous sources run during subscribe() on the calling thread.

Warning
Reference captures must outlive processing. The caller must synchronize data shared between subscriptions.
