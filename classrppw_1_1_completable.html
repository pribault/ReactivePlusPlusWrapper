Detailed Description

Cold source that completes without a value or signals an error.

Each subscription executes its own chain. Actions are deferred until subscription; their exceptions are forwarded through std::exception_ptr. Without a scheduler, synchronous actions run on the thread calling subscribe().

Warning
Reference captures must outlive processing. The caller must synchronize data shared between subscriptions.
