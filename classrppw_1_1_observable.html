Detailed Description

template<detail::Value T>
class rppw::Observable< T >

Cold source of zero or more values, followed by completion or an error.

Template Parameters
TUnqualified value type satisfying std::copyable.

Each subscription executes its own chain. Composing operators does not invoke producers. Without an explicit scheduler, synchronous processing runs on the thread calling subscribe(). Producer and operator exceptions are forwarded through std::exception_ptr. An error or completion terminates the subscription; no further events are delivered. Reactive objects are copyable and share their type-erased RPP representation, which may allocate. Operators return a new chain.

Warning
Reference captures must outlive their use, including asynchronous use. The caller must synchronize data shared between subscriptions. No backpressure mechanism is provided.

Subscribes the three callbacks and starts processing.

Template Parameters
NType of the callback receiving a value of type T.
EType of the callback receiving std::exception_ptr.
CType of the completion callback taking no arguments.
Parameters
onNextCallback invoked for each value.
onErrorTerminal error callback.
onCompleteTerminal normal-completion callback.
Returns
Shared cancellation handle, already disposed if the source terminates synchronously.
Precondition
All three callbacks must be const-invocable and must not throw.
Warning
An exception escaping a callback invokes std::terminate.
Note
Callbacks are retained throughout processing. Destroying the returned handle does not cancel the subscription. Callbacks of one subscription are serialized; concurrent cancellation does not interrupt a callback already in progress.
