Detailed Description

Copyable handle sharing the cancellation state of an RPP subscription.

Copies share cancellation; destroying a handle does not explicitly request cancellation. An empty handle is considered disposed.

Note
dispose() and isDisposed() delegate to thread-safe RPP operations. This does not permit concurrent assignment to the same handle object.
#pragma once
// rpp
#include <rpp/disposables/composite_disposable.hpp>
namespace rppw
{
class Disposable
{
public:
Disposable();
explicit Disposable(rpp::composite_disposable_wrapper disposable);
void dispose() const noexcept;
[[nodiscard]] bool isDisposed() const noexcept;
private:
rpp::composite_disposable_wrapper disposable_;
};
} // namespace rppw
